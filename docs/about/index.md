# About NUTRIx

**NUTRIx — Network for Computational Nutrition Science** is a DFG-funded
Scientific Network (2027–2029) of early-career researchers working at the
interface of nutrition and data science.

- [The network](network.md) — origin, rationale, objectives, and partnerships.
- [Members](members.md) — directory of network members.
- [Meetings](../meetings/index.md) — the annual in-person meetings and how to attend.
- [Funding](funding.md) — funding body, grant, and licensing.

## Coordination

The network is co-coordinated by:

- **Dr. Mattea Müller** — Peter L. Reichertz Institute for Medical Informatics, Hannover Medical School (MHH)
- **Dr. Fabian Eichelmann** — Department of Molecular Epidemiology, German Institute of Human Nutrition Potsdam-Rehbrücke (DIfE)
